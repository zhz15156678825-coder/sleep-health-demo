# 眠境 · 中文睡眠健康智能评估原型

**离线、可复现、只用于科研软件演示。全部数据为模拟数据；预测、状态推演、实验指标都不能用于诊断、治疗或证明健康效果。无真实受试者验证。**

## 快速运行

推荐 Python 3.11（支持 3.10–3.12）。解压后在 `sleep_health_demo` 文件夹打开终端。

Windows PowerShell：

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

macOS / Linux：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m streamlit run app.py
```

浏览器访问 http://127.0.0.1:8501 。首次安装需要网络；运行无需网络、账号、密钥或付费 API。通过 Ctrl+C 停止服务。如果端口占用，添加 `--server.port 8502`。建议始终用虚拟环境，避免与已有科学计算环境冲突。

Windows 已安装依赖后可双击 `run_windows.bat`。若没有 `py` 命令，使用已安装 Python 的完整路径替换。

## 五个页面

1. **睡眠仪表盘**：切换12名用户、30天时长/精力/压力趋势、最近指标、用户CSV导出。
2. **预测与解释**：明日精力回归、测试日回顾、下一天预测、标准化系数与单样本贡献、与基线比较。
3. **情境与智能体**：修改目标、偏好、信念、意图、情绪、可用时间、压力、夜班与社会约束；情境输入/离线问答；三智能体日志；候选比较；采纳意愿反馈和审计导出。
4. **实验对照**：相同时间留出集上的模型/基线/历史精力消融；完整情境与移除情境的并排分支比较；尚未开展的真实研究方案。
5. **数据与理论**：MWM和SCPS概念映射、实现限制、生活习惯规则来源、数据字典和全部数据导出。

## 一分钟体验路径

- 切到 U01，查看睡眠趋势。
- 在“预测与解释”查看 09.23 的局部贡献，再选择“下一天演示预测”。
- 在“情境与智能体”保存目标为“减轻睡前负担”、可用时间5分钟，再运行。
- 输入“安眠药剂量是多少”，再次运行，观察安全规则否决普通建议。
- 切换 U02，确认 U01 的状态与运行记录不会串到 U02。
- 在“实验对照”选“忙碌夜班”，观察移除心理情境后的不适配建议。

## 数据与预测协议

- 种子 `20261028`，12用户 × 30天 = 360行，从2026-09-01到09-30。已附CSV与初始状态JSON。
- `python core.py` 可重建两个示例文件。主观精力是含噪声的人工自回归函数，不是问卷测量或临床标签。生成机制详见 `docs/METHODS.md`。
- 截至 t 日晚间可知的输入预测 t+1 日精力。每人29个标签，共348个样本。09.02–09.22目标日期用于训练（252），09.23–09.30用于测试（96）。09.30行没有下一日标签，只能用于10.01演示预测。
- 所有滚动特征按用户分组，窗口结束于当日；无居中滚动、无向后填充、无未来睡眠输入。
- 填补器、标准化器与Ridge均只拟合训练集。α=10固定，不报告测试集最优调参结果。
- 测试为逐日单步预测，可使用已经观测到的当日精力；不是一次预测八天。已知用户的时间泛化不能替代新用户泛化。
- 页面显示MAE/RMSE，运行时真实计算，但只是在合成数据上的软件指标，不是现实验证结果。不保证复杂模型胜过基线。

## 理论与智能体

参考用户上传的两篇论文：

- Hao Fei & Yiran Zhao, *Mental World Modeling*, arXiv:2607.27201v1（2026-07-29），§3.3、§5.3–5.5。
- Belbachir et al., *Towards socio-cyber-physical systems: a software perspective amid AI breakthroughs*, Science China Information Sciences 69, 193101 (2026)，DOI https://doi.org/10.1007/s11432-026-5037-1 ，§2.3、§4。

本项目对理论进行领域化简化：物理—心理联合状态 → 当前用户的部分观察 → 物理行动与心理意图 → 定性假设后继状态 → 分支评分与安全否决。并非 MENTIS 实验复现，也未实现完整 POMDP、学习到的心理状态转移或大语言模型推理。论文原始PDF不随项目分发。具体映射和规则见 `docs/THEORY.md`。

三个智能体是可追踪的独立Python逻辑阶段：数据分析 → 知识规则 → 情境反馈。每次输出输入、输出、依赖、规则ID、候选分支、选择与运行摘要哈希；没有隐藏的模型思维链。

## 状态、隐私和安全

- 状态、运行记录、反馈保存在当前Streamlit会话；重启、断开后可能丢失。需要保留时下载JSON。示例 `profiles_demo.json` 是重建用初始状态，不是用户更新的持久数据库；界面从同一默认构造器初始化，暂不支持导入。
- 仅显式表单字段参与个性化。自由文本供离线安全关键词路由及审计，不会自动提取“只有5分钟”并覆盖状态，也不是通用聊天机器人。
- 信念、意图、情绪和自由文本社会约束可展示和更新，但当前只有目标、偏好、时间、压力与夜班参与规则评分。不会伪装成真实读心或复杂语义理解。
- 候选后继状态只是假设：不填造“精力提高X分”“采纳概率X%”或“用户已执行”。反馈只记录意愿。
- 安全关键词会阻止普通建议并转向人工帮助；这不是医疗分诊，不能排除漏检或误报。无处方、剂量、诊断及治疗方案。
- 生活习惯内容参考 [CDC About Sleep](https://www.cdc.gov/sleep/about/index.html)，医疗边界参考 [NHLBI Insomnia Treatment](https://www.nhlbi.nih.gov/health/insomnia/treatment)，访问2026-10-28。评分、时间阈值和分支转移为工程假设，不是医学指南。
- 默认仅监听127.0.0.1，关闭Streamlit使用统计。运行时不上传数据，但没有生产级身份认证、加密存储或权限系统，勿部署公网或输入敏感真实数据。


具体交付验证记录见 `docs/VERIFICATION.md`。测试通过仅说明所检查的软件行为，不代表医疗安全认证。

## 项目结构

```text
app.py                 中文Streamlit界面
core.py                生成数据、时序特征、模型、解释和三个逻辑智能体
requirements.txt       固定直接依赖
run_windows.bat        Windows启动入口
.streamlit/config.toml 本地监听与主题
data/                  360行CSV、数据字典、初始用户状态
examples/              示例完整协同记录和逐样本预测
docs/                  理论映射、方法、验证记录
tests/                 核心行为和界面测试
```

后续接入公开睡眠数据时，先检查许可、标签对应时间、用户ID与评估划分。公开PSG数据通常没有本项目所需的连续主观精力标签，不应直接宣称完成相同预测验证。
